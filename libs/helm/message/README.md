# @spartan-ng/helm/message

Secondary entry point of `@spartan-ng/helm`. It can be used by importing from `@spartan-ng/helm/message`.

Angular port of the [AI Elements `Message`](https://elements.ai-sdk.dev/components/message) component
suite (message bubble, actions, toolbar, and branch navigation). `MessageResponse` (Markdown/Streamdown
rendering) is intentionally not included yet — see the component README for details.
